## Data Notification Analysis
- Upload Data Notification Excel workbooks to start an analysis run.
- Cross-reference records with DACS Permission and Usage reports.
- Identify impacted applications and single users.
- Continue processing with partial results if a DACS report fails to fetch or parse.
- Display recent analysis runs on the dashboard.
- Record an audit log entry for each analysis run.

## Results Review
- Review impacted applications and single users for each run.
- View detailed records for each Data Notification.
- Export applications, single users, tracker items, and RIC results to Excel files.

## Action Tracker
- Track remediation status for each impacted Data Notification (Open or Closed).
- Add comments to tracker items.
- Search, filter by status, sort, and paginate tracker items.
- Retain tracker statuses and comments across subsequent analysis runs.

## RIC Analysis
- Verify if application logins consume Reuters Instrument Codes (RICs).
- Display summary metrics and a detailed results table.

## Settings and Access Control
- Authenticate users through Entra via the authentication service.
- Configure DACS Permission and Usage report URLs (restricted to administrators).
- Restrict configuration changes and access to the admin portal to administrators.
- Display application version details in the admin portal.
