## Authentication & Authorisation
- Users can sign in using email/password
- Users can sign in using Microsoft Entra
- Users can log out
- Users can view their profiles

## Getting Company Details
- Users can search for one company's details 
- Users can search for multiple companies' details at once
- Users can upload Excel spreadsheet with list of IDs and have missing details filled in
- User's can download past enriched spreadsheets
